指标定义与取值口径（延保 · 华为 · 增值 · 整体）
① 工单量 = 创维+酷开可售工单数量（延保）、上门可售工单数量（增值）、华为智慧屏安装工单数量（华为）。多月份区间下为所选区间合计。
② 延保成交率 = 商城延保订单数量 ÷ 创维+酷开可售工单数量（按工单量加权）。
③ 延保客单价 = 商城延保均价（跟踪看板 col25，按成交单数加权），代表每笔成交的平均延保金额；看板所有客单价口径（含可挽回测算）均用此值。
④ 完成率（延保 / 增值 / 整体） = 加权回款 ÷ 加权任务额（任务额取跟踪看板 col5 真实值，非回款÷完成率反推）；整体含延保+增值+其他，来自跟踪看板整体任务口径，用于管理层总览。
⑤ 增值单工单产出 = 增值回款 ÷ 上门可售工单数量（按工单量加权）。
⑥ 华为延保成交率 = 华为全质保延保订单 ÷ 华为智慧屏安装工单（按安装工单加权）；华为延保均价 = 华为延保回款 ÷ 华为延保订单。
⑦ 可挽回金额 /月　假设其他环节不变，仅将失血环节提升至基准水平，当月可增加的成交金额；多月份区间显示为「区间月均」。分三条线： ‑ 延保可挽回 = Σ 工单量×(基准成交率−实际成交率)×基准客单价 ＋ Σ 成交单数×(基准客单价−实际客单价)；
‑ 华为可挽回 = Σ 华为安装工单×(基准华为成交率−实际华为成交率)×华为延保均价（与「延保看板-华为专项」同算法）；
‑ 增值可挽回 = Σ 工单量×(基准单工单产出−实际单工单产出)；
‑ 整体可挽回 = 延保可挽回 ＋ 华为可挽回 ＋ 增值可挽回。
⑧ 时间进度 = 累计取值天数 ÷ 累计总天数（已完月按满月、未完月按实际取值天数混合；取值天数反推自「数据更新日」progress = (更新日−1) ÷ 当月天数）。
⑨ 进度差额（金额） = (完成率 − 时间进度) × 对应任务金额 = 实际回款 − 计划回款，为正=领先进度、为负=落后进度。
⑩ 日均工单量 = 工单量 ÷ 取值天数（已完月÷满月、未完月÷实际取值天数）。
⑪ 三大结构比率　占比0.5 = 多功能挂架 ÷(自备工单+0.5+带挂装工单)；占比1 =(普通+多功能挂架)÷(自备工单+带挂装工单)；保护器+8KHDMI占比 = 保护器HDMI ÷ 上门可售工单；华为挂架出库占比 = 华为高价值工单 ÷ 华为安装工单。
基准说明　默认「全国前25%」（取指标值最高的前25%实体、按工单量加权求均值），可切「全国均值 / 全国最佳」。各视图（延保 / 华为专项 / 增值 / 整体）的基准恒取全量，不随大区筛选变化；大区/办事处明细随筛选联动。
数据治理提示　现有看板尚未采集「开口率 / 报价率」——即师傅是否开口建议、是否明确报价。建议下一阶段接入派工/回访系统，使归因诊断从「成交」前移到「开口」。
使用节奏　每月 5 日更新 → 大区经理按诊断表领任务 → 月中检查处方执行 → 次月看环节指标是否回升。连续两月同一环节不改善的，问题不在师傅，在管理动作或产品本身。
汇报口径　对上汇报只讲三个数：体系覆盖率、关键环节同比提升幅度、试点大区与对照大区的客单价差异。
